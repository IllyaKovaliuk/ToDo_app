# ToDo_app

This project was created with Django Framework. Managing your tasks. Users cab create, remove, read information and delete tasks.

Features:

    -CRUD operations with tasks
    -Task status administration
    -Tags administration
Tech Stack

    -Python 3.9
    -Django 4.2
    -Bootstrap
How to use this project

1. Clone the repository: git clone https://github.com/IllyaKovaliuk/ToDo_app
2. Chose the "developer" branch
3. Navigate to the project directory: cd myproject
4. Create venv and activate it python -m venv venv source venv/bin/activate
5. Install all libraries pip install -r requirements.txt
6. Run server python manage.py runserver
